# CheapAI 自动化测试与验收规范

## 1. 文档目标

本文档用于定义 CheapAI 的自动化测试分层、验收环境、覆盖范围和发布前验收标准。

说明：

1. 本文档是实现阶段的测试基准
2. 不允许只用单一 E2E 替代所有测试
3. 涉及抓取、真实模型调用、反造假判断的能力，必须在真实环境做受控验收

---

## 2. 测试总原则

## 2.1 分层测试

必须同时覆盖：

1. 单元测试
2. 集成测试
3. API 契约测试
4. 前端组件测试
5. E2E 测试
6. 真实环境测试

## 2.2 用户端与管理端独立测试

规则：

1. `web-public` 独立构建、独立测试、独立 E2E
2. `web-admin` 独立构建、独立测试、独立 E2E
3. 不建立共享前端测试模板

## 2.3 公共排行与自助测试分离验证

必须单独验证：

1. 平台定时测试结果会进入公共排行
2. 用户自助测试结果不会进入公共排行

---

## 3. 测试工具链

## 3.1 后端

1. `xUnit`
2. `FluentAssertions`
3. `WebApplicationFactory`
4. `Testcontainers`

## 3.2 用户端

1. `Vitest`
2. `@testing-library/react`
3. `Playwright`

## 3.3 管理端

1. `Vitest`
2. `@testing-library/react`
3. `Playwright`

## 3.4 契约与类型

1. `Swagger / OpenAPI`
2. `openapi-typescript`

---

## 4. 环境分层

## 4.1 本地开发环境

用途：

1. 日常开发
2. 单元测试
3. 本地集成测试

要求：

1. 启动真实 MySQL
2. 启动真实 Redis
3. 启动真实 Hangfire
4. 用户端和管理端都能独立运行

## 4.2 CI 环境

用途：

1. PR 校验
2. 自动化回归

要求：

1. 使用真实 MySQL 容器
2. 使用真实 Redis 容器
3. 使用真实 Hangfire 存储
4. 不允许只 Mock 基础设施
5. 外部中转站调用允许使用可控测试桩

## 4.3 预发布 / 夜间真实环境

用途：

1. 真实站点抓取验收
2. 真实模型测试验收
3. 真实风险识别验收
4. 自助测试冒烟

要求：

1. 使用真实站点地址
2. 使用真实测试账号
3. 使用真实 API Key
4. 使用真实抓取规则

---

## 5. 测试数据策略

## 5.1 本地与 CI 测试数据

使用可控种子数据：

1. 基础站点种子
2. 基础模型种子
3. 报价快照种子
4. 测试记录种子
5. 风险证据种子

## 5.2 真实环境测试数据

必须提前准备：

1. 至少 1 个真实价格抓取源
2. 至少 1 个真实测试站点
3. 至少 1 个真实 API Key
4. 至少 1 个可复现的风险样本

## 5.3 数据隔离

规则：

1. 真实环境测试账号不得和生产商业账号混用
2. 自助测试环境与平台定时测试环境分账
3. API Key 不得明文写入测试日志

---

## 6. 后端自动化测试

## 6.1 单元测试

必须覆盖：

1. 实际折算价计算
2. 可用性聚合
3. 稳定性评分
4. 速度评分
5. 综合性价比评分
6. 站点整体评分
7. 风险分计算
8. 风险命中后补测触发
9. DTO 校验

### 验收标准

1. 核心算法覆盖率必须完整
2. 边界输入必须有测试：
   - 空集合
   - 极值
   - 非法参数
   - 四舍五入与精度问题

## 6.2 集成测试

必须覆盖：

1. 管理员登录流程
2. 站点 CRUD
3. 模型 CRUD
4. 抓取结果写入
5. 测试结果写入
6. 风险证据写入
7. 排行快照写入
8. 审核流
9. 文章管理

### 技术要求

1. 使用 `WebApplicationFactory`
2. 使用 `Testcontainers` 启动 MySQL / Redis
3. 不能只 Mock Repository

## 6.3 任务测试

必须覆盖：

1. Hangfire 任务注册
2. 定时抓取任务
3. 定时测试任务
4. 风险重算任务
5. 排行刷新任务
6. 失败重试
7. 分布式锁冲突

### 验收标准

1. 同一个站点同一窗口重复任务不能并发重复执行
2. 首次高风险命中必须能产生补测任务

---

## 7. 用户端自动化测试

## 7.1 组件测试

必须覆盖：

1. 榜单表格组件
2. 风险标签组件
3. 站点详情卡片
4. 趋势图容器
5. 自助测试表单

## 7.2 页面 E2E

必须覆盖：

1. 首页加载
2. 模型排行页切换模型
3. 模型排行页筛选风险
4. 进入站点详情页
5. 查看风险摘要
6. P1 自助测试提交与结果查看
7. P2 站点提交流程

## 7.3 SEO 验收

必须覆盖：

1. 榜单页 SSR 输出
2. 详情页 SSR 输出
3. Metadata 输出
4. Canonical / Title / Description 存在

---

## 8. 管理端自动化测试

## 8.1 组件测试

必须覆盖：

1. 登录表单
2. 站点列表页
3. 模型列表页
4. 风险列表页
5. 审核列表页
6. 文章编辑页

## 8.2 页面 E2E

必须覆盖：

1. 登录
2. 站点新增 / 编辑 / 下线
3. 模型新增 / 编辑
4. 查看抓取任务
5. 查看测试任务
6. 查看风险详情
7. 标记误报
8. 审核通过 / 驳回
9. 文章发布 / 下线

---

## 9. API 契约测试

## 9.1 目标

确保后端接口变化不会悄悄破坏两个独立前端。

## 9.2 规则

1. 后端生成 OpenAPI 文档
2. `web-public` 独立生成自己的 API types/client
3. `web-admin` 独立生成自己的 API types/client
4. 不建立共享前端 SDK 包

## 9.3 验收点

1. OpenAPI 生成成功
2. 两个前端类型生成成功
3. 生成后前端编译通过

---

## 10. 真实环境自动验收

## 10.1 验收范围

必须至少覆盖：

1. 一个真实价格抓取源
2. 一个真实中转站测试账号
3. 一个真实风险识别样本
4. 一条自助测试完整链路

## 10.2 夜间任务

建议每天夜间执行：

1. 抓取验收任务
2. 平台测试验收任务
3. 风险识别验收任务
4. 排行刷新验收任务
5. 自助测试冒烟

## 10.3 输出内容

自动生成真实环境验收报告，至少包含：

1. 成功率
2. 失败站点
3. 风险命中
4. 排行刷新结果
5. 需要人工处理的异常

---

## 11. P0 / P1 / P2 验收标准

## 11.1 P0 验收

必须可运行：

1. 后台收录
2. 价格抓取
3. 平台定时测试
4. 基础风险识别
5. 模型稳定性排行
6. 模型价格排行
7. 精简站点详情页

## 11.2 P1 验收

必须可运行：

1. 综合性价比排行
2. 中转站整体评分
3. 价格趋势图
4. 稳定性趋势图
5. 风险详情与误报复核
6. 自助测试安全版

## 11.3 P2 验收

必须可运行：

1. 第三方模型能力榜
2. 公开提交
3. 审核流
4. 企业筛选增强
5. 文章管理

---

## 12. 不通过条件

出现以下情况视为不通过：

1. 用户端和管理端共用前端模板或共享组件依赖成为硬前提
2. 自助测试结果进入公共排行
3. 风险分与文档规则不一致
4. 排行直接从明细表实时拼装
5. 抓取、测试、风险任务无法自动重试和追踪
6. 真实环境验收未覆盖真实站点与真实账号

---

## 13. 当前结论

CheapAI 的自动化测试与验收必须满足三个前提：

1. 双前端独立测试
2. 后端任务与算法全覆盖测试
3. 真实环境强制验收

后续实现时，任何功能只有在通过本规范定义的测试层级后，才可视为完成。
