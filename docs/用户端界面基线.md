# 用户端界面基线

本文件用于约束后续 `src/frontend/web-public` 的页面开发。新页面默认参考当前首页与列表页实现，不再单独发明新的视觉语言。

## 参考源

- 设计来源：`/.codex/DESIGN.md`
- 全局 token：`/src/frontend/web-public/app/globals.css`
- 公共头部：`/src/frontend/web-public/app/components/PublicHeader.tsx`
- 公共页脚：`/src/frontend/web-public/app/components/PublicFooter.tsx`
- 公共页头：`/src/frontend/web-public/app/components/PublicPageHero.tsx`
- 首页母版：`/src/frontend/web-public/app/page.tsx`
- 自测模块：`/src/frontend/web-public/app/components/HomeTestWorkbench.tsx`

## 必须遵守

1. 继续使用白色画布、深色正文、单一品牌强调色 `#ff385c`，不要再回到偏 Apple 风的冷蓝高透明毛玻璃主风格。
2. 页面结构默认采用“页头说明 + 数据摘要 + 主内容区块”的三段式，不要直接把表格顶到页面最上方。
3. 卡片、表格、表单和榜单都沿用 `globals.css` 中现有 token 与类名，优先复用，不重复造样式。
4. 用户端主按钮统一用品牌红，次按钮保持白底描边，避免引入新的主色按钮体系。
5. 需要解释决策逻辑的页面，优先使用卡片化说明，而不是长段落堆文案。
6. 列表页仍可用表格，但首页和核心入口页优先用“卡片 + 排行条目”而不是纯后台式表格。

## 新页面落地顺序

1. 先判断是否能复用 `PublicPageHero`。
2. 再判断主体内容属于卡片列表、榜单、表格还是表单。
3. 只有现有样式无法覆盖时，才允许往 `globals.css` 增补新类；新增前优先抽象为公共类，不写页面私有硬编码样式。
