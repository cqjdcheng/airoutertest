# 腾讯问卷设计稿（精简版）：AI 中转站与中转比价网用户调研

## 1. 问卷目标

本问卷用于验证两件事：

1. 用户选择 AI 中转站时，最在意什么、最痛的点是什么。
2. 用户是否真的需要一个“中转比价 + 稳定性测试 + 反造假”的平台。

建议控制答题时长在 `3-4 分钟`。

---

## 2. 腾讯问卷基本设置建议

### 2.1 问卷标题

`AI 中转站使用需求调研`

### 2.2 问卷副标题

`调研你对 AI 中转站价格、稳定性、反造假和比价平台的真实需求，预计 3-4 分钟。`

### 2.3 问卷说明

可直接放在问卷开头：

> 你好，我们正在调研 AI API 用户对中转站的选择标准、使用痛点，以及对“AI 中转比价平台”的需求。问卷匿名，预计耗时 3-4 分钟。感谢你的参与。

### 2.4 提交后文案

`感谢填写。如果你愿意参与后续内测，可在最后留下联系方式。`

---

## 3. 问卷结构

建议分为 4 页：

1. 用户背景
2. 中转站使用需求
3. 中转比价网需求
4. 使用意愿与补充建议

---

## 4. 题目设计

以下为精简后的推荐题目，共 `12 个核心题 + 1 个可选联系方式`。

### 第 1 页：用户背景

#### Q1. 你目前属于哪类 AI 用户？

- 题型：`多选`
- 必答：`是`
- 选项：
  - 个人开发者 / 上班族
  - 企业采购 / 企业技术负责人
  - 创业团队 / 工作室
  - 内容创作者 / 自媒体
  - 学生 / 研究者
  - 羊毛党 / 低价导向用户
  - 其他


#### Q3. 你目前是否使用过 AI 中转站？

- 题型：`单选`
- 必答：`是`
- 选项：
  - 正在长期使用
  - 偶尔使用
  - 用过，但后来放弃
  - 没用过，但考虑过
  - 完全没用过

---

### 第 2 页：中转站使用需求

#### Q4. 你使用或考虑使用中转站的主要原因是什么？

- 题型：`多选`
- 必答：`是`
- 选项：
  - 比官方更便宜
  - 想用更多模型
  - 支付更方便
  - 想找稳定的备用通道
  - 想白嫖或低成本试用
  - 企业内部统一采购更方便
  - 其他

#### Q5. 你选择中转站时最看重哪些因素？

- 题型：`多选`
- 必答：`是`
- 说明：`最多选 3 项`
- 选项：
  - 实际折算后价格
  - 模型真实可用
  - 成功率 / 可用性
  - 长期稳定性
  - 响应速度
  - 是否支持开票
  - 是否支持退款
  - 是否有文档
  - 支持模型是否足够多
  - 是否能识别造假 / 偷换模型
  - 站点存活时间长
  - 客服或问题处理速度

#### Q6. 你在使用中转站时最常遇到哪些问题？

- 题型：`多选`
- 必答：`是`
- 选项：
  - 价格不透明
  - 标价便宜，但实际并不便宜
  - 模型不可用
  - 成功率不稳定
  - 响应速度慢
  - 模型疑似被降级
  - 模型疑似被偷换
  - 返回缓存假响应
  - 充值后服务变差
  - 不支持退款 / 开票 / 文档不全
  - 其他

#### Q7. 如果一个平台能帮你识别中转站风险，你最希望识别哪些问题？

- 题型：`多选`
- 必答：`是`
- 选项：
  - 缓存假响应
  - 模型偷换
  - 降级模型冒充高阶模型
  - 价格虚标
  - 响应伪造
  - 上游 / 号池不稳定
  - 我并不关心反造假

---

### 第 3 页：中转比价网需求

#### Q8. 如果有一个“AI 中转比价网”，你最想用哪些功能？

- 题型：`多选`
- 必答：`是`
- 选项：
  - 按模型查看最便宜站点
  - 按模型查看最稳定站点
  - 按模型查看综合性价比排行
  - 查看中转站整体评分
  - 查看中转站详情页
  - 查看历史价格和稳定性变化
  - 查看反造假状态、风险分和证据
  - 查看第三方模型能力排行
  - 直接测试某个站点 + 模型
  - 按“开票 / 退款 / 文档 / 稳定性”筛选
  - 提交新的中转站给平台收录

#### Q9. 如果平台支持“自己输入站点地址、API 密钥、模型名，然后发起测试”，你会用吗？

- 题型：`单选`
- 必答：`是`
- 选项：
  - 经常会用
  - 偶尔会用
  - 只在怀疑站点有问题时使用
  - 不太会用
  - 完全不会用

#### Q10. 你对这种“自助测试功能”最大的顾虑是什么？

- 题型：`多选`
- 必答：`是`
- 选项：
  - API 密钥安全
  - 测试结果不可信
  - 操作太复杂
  - 怕测试消耗额度
  - 怕平台保存我的信息
  - 没这个需求
  - 其他

#### Q11. 下面这些页面或能力里，哪个最值得优先做好？

- 题型：`单选`
- 必答：`是`
- 选项：
  - 模型价格排行
  - 模型稳定性排行
  - 综合性价比排行
  - 中转站详情页
  - 风险识别 / 反造假
  - 用户自助测试
  - 模型能力排行

---

### 第 4 页：使用意愿与补充建议

#### Q12. 如果这个平台数据真实、更新及时，你会愿意把它作为“找中转站”的常用入口吗？

- 题型：`单选`
- 必答：`是`
- 选项：
  - 一定会
  - 大概率会
  - 看数据是否真的可信
  - 不一定
  - 不会

#### Q13. 你对 AI 中转站或中转比价网还有什么建议？

- 题型：`填空题`
- 必答：`否`
