# CheapAI 现有功能文档

更新时间：2026-05-14

本文档描述当前代码库已经实现并通过本地构建验证的功能。本文档以现状为准，不描述尚未落地的远期规划。

## 1. 系统边界

CheapAI 当前由三部分组成：

1. 用户端：`src/frontend/web-public`，Next.js 应用，面向公开用户。
2. 管理端：`src/frontend/web-admin`，Umi Max + Ant Design Pro 应用，面向管理员。
3. 后端 API：`src/backend`，ASP.NET Core API，统一提供公开接口、后台接口、数据库初始化和基础任务能力。

本地默认访问地址：

| 服务 | 地址 | 说明 |
|---|---|---|
| 后端 API | `http://127.0.0.1:5157` | 健康检查：`/api/health` |
| 管理端 | `http://127.0.0.1:8000` | 后台登录、模型、站点、报价等管理 |
| 用户端 | `http://127.0.0.1:3000` | 首页、模型目录、站点目录、自测等 |

## 2. 用户端功能

### 2.1 首页

首页当前承担以下功能：

1. 展示平台核心指标：站点数、模型数、测试次数。
2. 展示热门模型自测入口。
3. 展示热门模型的低价快照入口。
4. 热门模型不再写死，来源于后台模型列表中的 `is_hot` 和 `sort_order`。
5. 如果没有设置热门模型，首页会按启用模型的排序值回退展示前若干模型。

首页热门模型字段口径：

| 字段 | 用途 |
|---|---|
| `modelSlug` | 用户端路由和模型标识 |
| `modelName` | 页面展示名称 |
| `requestName` | 发起测试时使用的真实模型请求名称 |
| `apiType` | 接口类型，当前支持 `openai` 和 `anthropic` |

### 2.2 用户自助测试

用户自助测试组件当前用于让用户输入：

1. API 接口地址。
2. API Key。
3. 目标模型。
4. 是否流式测试。

核心行为：

1. 快捷模型来自后台热门模型。
2. 展示用 `modelName`。
3. 请求用 `requestName`，例如展示 `GPT 5.5`，实际请求 `gpt-5.5`。
4. 用户输入自定义模型时，自定义值优先。
5. API Key 不落库，仅用于当前测试请求。
6. 测试结果写入 `self_tests`，并同步生成统一测试记录 `test_records`。

### 2.3 模型目录

模型目录页当前展示：

1. 模型名称。
2. 模型供应商。
3. 模型请求名称。
4. 官方价格。
5. 当前最便宜中转站。
6. 中转站覆盖数量。
7. 稳定性和风险摘要。
8. 跳转模型排行页。

模型名称和请求名称已经拆分：

| 字段 | 示例 | 说明 |
|---|---|---|
| `modelName` | `GPT 5.5` | 用户端展示名称 |
| `requestName` | `gpt-5.5` | API 调用时使用的模型名 |
| `officialModelId` | `openai/gpt-5.5` | 第三方目录原始 ID |

### 2.4 站点目录与站点详情

站点相关用户端功能包括：

1. 公开站点列表。
2. 站点详情页。
3. 站点支持模型。
4. 站点价格快照。
5. 最近测试结果。
6. 风险摘要。

站点详情当前以站点为中心组织数据，模型维度的数据来自 `relay_offers`、`model_ranking_snapshots` 和 `test_records`。

### 2.5 测试记录页

测试记录页用于展示统一测试记录：

1. 平台测试记录。
2. 用户自测记录。
3. 测试站点。
4. 测试模型。
5. 首 token 时间。
6. 完整响应耗时。
7. 风险分和风险等级。
8. 原始检测项摘要。

### 2.6 文章与提交入口

当前已存在基础内容能力：

1. 文章列表。
2. 文章详情。
3. 站点提交入口。
4. 提交结果进入后台审核列表。

## 3. 管理端功能

### 3.1 登录与后台框架

管理端支持：

1. 管理员登录。
2. 登录状态保存。
3. 登录后跳转后台主页。
4. 受保护页面通过 `AuthGuard` 控制访问。
5. 菜单按 Umi 路由配置生成。

默认本地管理员：

| 字段 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `ChangeMe123!` |

### 3.2 后台总览

后台总览用于显示平台管理概览，包括站点、模型、测试、风险等运营数据入口。

### 3.3 模型管理

模型管理是当前重点模块，已实现：

1. 模型列表。
2. 新增模型弹窗。
3. 编辑模型弹窗。
4. 模型详情读取。
5. 模型状态切换：启用、隐藏、弃用。
6. OpenRouter 模型抓取预览。
7. OpenRouter 模型批量导入。
8. 模型供应商自动关联。
9. 模型排序在列表内直接编辑。
10. 热门模型在列表内通过开关直接设置。

模型核心字段：

| 字段 | 说明 |
|---|---|
| 模型名称 | 用户端展示名，例如 `GPT 5.5` |
| 模型请求名称 | API 调用名，例如 `gpt-5.5` |
| 模型供应商 | 关联 `model_providers` |
| 接口类型 | `openai` / `anthropic` |
| 模型说明 | OpenRouter 或手工录入说明 |
| 官方价格 | 输入价和输出价，单位 USD / 1M tokens |
| 能力评分 | 来自 OpenRouter 解析字段 |
| 排序 | `sort_order`，越小越靠前 |
| 热门 | `is_hot`，控制用户端首页展示 |

OpenRouter 抓取规则：

1. 请求 `https://openrouter.ai/api/v1/models`。
2. `officialModelId` 保留 OpenRouter 原始 ID，例如 `openai/gpt-5.4`。
3. `requestName` 从原始 ID 拆出最后一段，例如 `gpt-5.4`。
4. `displayName` 去掉供应商前缀，例如 `OpenAI: GPT-5.4` 归一为 `GPT-5.4`。
5. `providerSlug` 从原始 ID 第一段提取，例如 `openai`。
6. `providerName` 优先使用内置映射或展示名前缀。
7. `apiType` 按供应商或模型名推断，Anthropic/Claude 为 `anthropic`，其他默认 `openai`。
8. 价格从 OpenRouter token 单价换算为 USD / 1M tokens。
9. 能力评分根据上下文长度、最大输出、工具调用、推理、结构化输出、多模态等字段生成。

### 3.4 模型供应商管理

模型供应商已独立维护：

1. 供应商列表。
2. 新增供应商。
3. 编辑供应商。
4. 状态管理。
5. 排序管理。
6. 模型导入时可自动创建缺失供应商。

模型通过 `provider_id` 关联供应商，同时保留 `vendor` 作为兼容字段。

### 3.5 中转站管理

中转站管理已实现：

1. 中转站列表。
2. 新增中转站弹窗。
3. 编辑中转站弹窗。
4. 状态切换。
5. 基本资料维护。
6. 是否支持退款、发票、文档等企业筛选字段。
7. 中转详情弹窗。
8. 详情内使用 3 个 Tab 展示：基本信息、模型信息、最近测试记录。

中转模型报价录入支持：

1. 选择已有模型。
2. 手工录入模型。
3. 录入模型请求名称。
4. 录入接口类型。
5. 录入官方价格。
6. 录入站点价格。
7. 录入充值倍率和赠送倍率。
8. 自动计算折算价。

### 3.6 中转价格抓取

中转站管理页已实现参考 one-tracker 风格的价格抓取：

1. 支持 `auto`、`newapi`、`oneapi`、`onehub` 类型。
2. 支持填写 API Key。
3. 支持充值倍率。
4. 支持赠送倍率。
5. 支持价格基线。
6. 支持指定用户分组。
7. 抓取后生成报价预览并写入表单。
8. 优先通过 `requestName` 匹配已有模型，再回退匹配 `officialModelId`。

### 3.7 站点设置

站点设置当前支持：

1. 站点名称。
2. 站点图标地址。
3. 用户端读取公开站点设置。
4. 管理端更新站点设置。

### 3.8 运营数据

管理端已包含以下运营入口：

1. 报价快照。
2. 测试记录。
3. 风险中心。
4. 任务执行记录。
5. 站点提交审核。
6. 文章管理。

## 4. 后端功能

| 方法 | 路径 | 说明 |
|---|---|---|
