# CheapAI 后台管理端现有功能文档

更新时间：2026-05-14

本文档只描述当前后台管理端已经落地的功能。后台管理端工程位于 `src/frontend/web-admin`，技术栈为 Umi Max + Ant Design Pro，默认本地地址为 `http://127.0.0.1:8000`。

## 1. 后台定位

后台管理端面向管理员，核心目标是维护中转站、模型、模型提供商、报价、测试、风险、内容和站点配置。

当前后台菜单分组：

| 分组 | 页面 |
|---|---|
| 工作台 | `/dashboard` |
| 主数据 | `/sites`、`/models`、`/model-providers`、`/offers` |
| 运营与风控 | `/tests`、`/risks`、`/jobs` |
| 内容与配置 | `/submissions`、`/articles`、`/settings` |

## 2. 登录与权限

### 2.1 登录

页面路径：`/login`

功能：

1. 管理员输入用户名和密码登录。
2. 登录成功后保存 Access Token。
3. Refresh Token 由后端通过 HttpOnly Cookie 管理。
4. 登录成功后跳转后台主页。
5. 已登录用户访问登录页时可进入后台。

默认本地管理员：

| 字段 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `ChangeMe123!` |

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/auth/login` | 登录 |
| POST | `/api/v1/auth/refresh` | 刷新 token |
| POST | `/api/v1/auth/logout` | 登出 |
| GET | `/api/v1/auth/me` | 当前管理员 |

### 2.2 路由保护

后台通过 `AuthGuard` 控制受保护页面访问：

1. 未登录访问后台页面会跳转登录页。
2. 请求返回 401 时自动尝试刷新 token。
3. 刷新失败后清理登录态并回到登录页。
4. 菜单选中状态基于 Umi 路由配置。

页面路径：`/dashboard`

工作台提供管理入口和运营概览：

1. 站点管理入口。
2. 模型目录入口。
3. 风险中心入口。
4. 线索审核入口。
5. 报价、测试、风险等数据模块的快捷导航。

## 4. 中转站点管理

页面路径：`/sites`

代码入口：`src/frontend/web-admin/src/pages/sites/index.tsx`

### 4.1 列表能力

中转站点列表支持：

1. 分页展示站点。
2. 展示站点名称、slug、API Base URL、官网、状态。
3. 展示企业属性：支持退款、支持发票、有文档。
4. 展示创建时间和更新时间。
5. 修改站点状态。
6. 打开新增弹窗。
7. 打开编辑弹窗。
8. 打开详情弹窗。

### 4.2 新增与编辑弹窗

新增和编辑中转站均为弹窗，不再跳转单独页面。

可维护字段：

| 字段 | 说明 |
|---|---|
| 站点名称 | 中转站展示名 |
| slug | 站内唯一标识 |
| API Base URL | 中转 API 地址 |
| 官网 URL | 公开官网 |
| 说明 | 管理说明 |
| 是否支持退款 | 企业筛选字段 |
| 是否支持发票 | 企业筛选字段 |
| 是否有文档 | 企业筛选字段 |
| 文档 URL | 文档入口 |
| 邀请链接 | 用户跳转入口 |
| 近期体验 | 管理端记录 |
| 报价列表 | 该站点支持模型和价格 |

### 4.3 中转详情弹窗

详情以弹窗展示，包含 3 个 Tab：

| Tab | 内容 |
|---|---|
| 基本信息 | 站点基础资料、企业属性、邀请链接、近期体验 |
| 模型信息 | 该站点支持的模型、官方价格、站点价格、折算价、来源 |
| 最近测试记录 | 模型、状态、首 token、完整耗时、风险分、测试时间 |

### 4.4 报价录入

报价录入支持：

1. 选择已有模型。
2. 手工新增模型。
3. 录入模型请求名称。
4. 录入接口类型。
5. 录入官方输入价和输出价。
6. 录入站点输入价和输出价。
7. 录入充值倍率。
8. 录入赠送倍率。
9. 自动计算折算输入价和折算输出价。

### 4.5 中转价格抓取

价格抓取参考 one-tracker 风格实现。

当前支持：

| 参数 | 说明 |
|---|---|
| 类型 | `auto` / `newapi` / `oneapi` / `onehub` |
| API Base URL | 待抓取中转地址 |
| API Key | 用于调用中转站管理或模型接口 |
| 充值倍率 | 用于折算实际成本 |
| 赠送倍率 | 用于折算实际成本 |
| 价格基线 | 用于解析站点标价 |
| 用户分组 | 用于部分 NewAPI/OneAPI 分组价格 |

抓取后生成报价预览，并可写入站点表单。

模型匹配顺序：

1. 优先按抓取出的 `requestName` 匹配 `models.request_name`。
2. 再按 `officialModelId` 匹配 `models.official_model_id`。
3. 未匹配时允许手工或自动新增模型。

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/admin/sites` | 站点列表 |
| GET | `/api/v1/admin/sites/{id}` | 站点详情 |
| POST | `/api/v1/admin/sites` | 新增站点 |
| PUT | `/api/v1/admin/sites/{id}` | 更新站点 |
| PATCH | `/api/v1/admin/sites/{id}/status` | 修改站点状态 |
| POST | `/api/v1/admin/sites/pricing-preview` | 抓取价格预览 |

## 5. 模型目录管理

页面路径：`/models`

代码入口：`src/frontend/web-admin/src/pages/models/index.tsx`

### 5.1 列表能力

模型列表支持：

1. 分页展示模型。
2. 展示模型名称、请求名称、供应商、接口类型、官方 ID。
3. 展示官方输入价和输出价。
4. 展示能力评分和评分来源。
5. 展示状态。
6. 列表内直接修改排序。
7. 列表内直接设置热门模型。
8. 修改模型状态。
9. 新增模型弹窗。
10. 编辑模型弹窗。
11. OpenRouter 抓取预览。
12. 批量导入模型。

### 5.2 模型核心字段

| 字段 | 说明 |
|---|---|
| 模型名称 | 用户端展示名，例如 `GPT-5.4` |
| 模型请求名称 | API 真实调用名，例如 `gpt-5.4` |
| 模型供应商 | 关联 `model_providers` |
| 接口类型 | `openai` / `anthropic` |
| Official ID | OpenRouter 原始 ID，例如 `openai/gpt-5.4` |
| 模型说明 | 来自抓取或手工维护 |
| 官方输入价 | USD / 1M tokens |
| 官方输出价 | USD / 1M tokens |
| 能力评分 | 当前来自 OpenRouter 解析 |
| 排序 | `sort_order`，越小越靠前 |
| 热门 | `is_hot`，控制用户端首页和首页测试模块展示 |
| 状态 | `active` / `hidden` / `deprecated` |

### 5.3 新增与编辑

新增和编辑模型均使用弹窗。

手工新增模型时必须补齐：

1. 模型名称。
2. 模型请求名称。
3. 模型供应商。
4. 接口类型。
5. Official ID。

### 5.4 OpenRouter 抓取

后台模型抓取来源为 OpenRouter，不抓取中转站自己的模型作为主模型目录。

抓取规则：

1. 请求 `https://openrouter.ai/api/v1/models`。
2. OpenRouter 原始 ID 写入 `official_model_id`。
3. 原始 ID 最后一段写入 `request_name`。
4. 展示名去掉供应商前缀，避免模型名称重复携带厂商。
5. 原始 ID 第一段映射为供应商 slug。
6. 抓取时自动创建或关联模型供应商。
7. Claude / Anthropic 模型写入 `api_type = anthropic`。
8. 其他模型默认写入 `api_type = openai`。
9. token 单价换算为 USD / 1M tokens。
10. 基于上下文长度、最大输出、工具调用、推理、结构化输出、多模态等信息计算能力评分。

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/admin/models` | 模型列表 |
| GET | `/api/v1/admin/models/{id}` | 模型详情 |
| POST | `/api/v1/admin/models` | 新增模型 |
| PUT | `/api/v1/admin/models/{id}` | 更新模型 |
| PATCH | `/api/v1/admin/models/{id}/status` | 修改状态 |
| PATCH | `/api/v1/admin/models/{id}/metadata` | 修改排序和热门 |
| POST | `/api/v1/admin/models/import-preview` | 通用导入预览 |
| POST | `/api/v1/admin/models/openrouter-preview` | OpenRouter 抓取预览 |
| POST | `/api/v1/admin/models/import` | 批量导入模型 |

## 14. 当前限制

1. 后台 Umi dev 服务直接 GET 子路由可能返回 `Cannot GET /xxx`，根路径进入后由前端路由跳转正常。
2. 当前权限模型只有管理员登录态，未细分角色权限。
3. 中转详情仍保留 `/sites/:id` 旧路由页面，但当前主流程已改为列表内详情弹窗。
4. 任务触发接口当前主要写入任务或日志，完整调度执行能力以后端实现为准。
