# CheapAI 数据库设计文档

## 1. 文档目标

本文档用于定义 CheapAI 项目的数据库结构、字段、约束、索引和数据可见性边界。

说明：

1. 本文档基于当前需求、功能方案和技术规范
2. 数据库统一采用 `MySQL 8.4 LTS`
3. ORM 统一采用 `SqlSugar`

---

## 2. 全局设计约定

## 2.1 命名规范

1. 表名统一使用 `snake_case` 复数形式
2. 字段名统一使用 `snake_case`
3. 主键统一命名为 `id`
4. 外键统一命名为 `{entity}_id`

## 2.2 主键与时间

1. 主键统一使用 `BIGINT UNSIGNED`
2. 时间统一使用 UTC
3. 推荐时间类型：
   - `DATETIME(3)`

## 2.3 审计字段

主业务表统一包含：

1. `id`
2. `created_at`
3. `updated_at`
4. `deleted_at`
5. `created_by`
6. `updated_by`

说明：

1. `deleted_at` 为空表示未删除
2. 业务主数据采用软删除
3. 日志、快照、证据表采用追加写，不做软删除

## 2.4 金额与价格精度

所有金额字段统一使用：

`DECIMAL(18,6)`

所有公开展示价格统一按 `USD` 聚合。

## 2.5 JSON 字段

可使用 `JSON` 类型存储：

1. 抓取原始结果摘要
2. 风险证据结构
3. 支付方式数组
4. 近期测试样本摘要

但主业务查询字段必须拆成独立列，不能全部塞 JSON。

## 4. 可见性分层

## 4.1 公开可见字段

只能出现在用户端接口中的字段，例如：

1. 站点名称
2. 站点简介
3. 支持开票 / 退款 / 文档
4. 当前价格
5. 测试摘要
6. 风险摘要
7. 文章内容

## 4.2 后台专有字段

只允许管理端查看，例如：

1. 内部测试账号摘要
2. 抓取失败日志
3. 任务执行细节
4. 风险人工复核备注

## 4.3 内部使用字段

只供后台任务、日志和聚合使用，不直接出现在公开接口中，例如：

1. API Key 脱敏片段
2. 抓取原始快照引用
3. 风险原始证据 JSON
4. 任务锁键

## 6. 关键关系说明

1. 一个 `relay_site` 可以有多个 `site_channels`
2. 一个 `relay_site` 可以支持多个 `models`
3. 一个 `relay_offer` 绑定一个站点、一个模型、零或一个渠道
4. 一个 `test_job` 会产生零到多条 `test_records`
5. 一条 `test_record` 可以产生零到多条 `risk_evidences`
6. `model_ranking_snapshots` 和 `site_ranking_snapshots` 都是聚合表
7. `site_submissions` 审核通过后可转换为 `relay_sites`

---

## 7. 索引策略摘要

必须优先保证以下查询：

1. 模型榜单查询
2. 站点详情查询
3. 站点-模型测试时间序列查询
4. 风险中心按状态和时间查询
5. 审核列表按状态和创建时间查询

因此重点索引方向为：

1. `(model_id, snapshot_at, rank_position)`
2. `(site_id, model_id, created_at DESC)`
3. `(review_status, created_at DESC)`
4. `(status, created_at DESC)`

## 8. 当前结论

数据库设计遵循三个核心原则：

1. 主数据、日志、快照分层
2. 公开字段、后台字段、内部字段分层
3. 排行用快照，不用实时拼装

后续实现时：

1. 可以直接按本设计建表
2. API 设计文档必须严格引用这里的表和字段
## 当前实现修订：模型字段口径

截至 2026-05-14，模型主数据已补充以下字段，后续设计以本节为准：

| 字段 | 类型 | 说明 |
|---|---|---|
| `provider_id` | BIGINT UNSIGNED NULL | 关联 `model_providers.id` |
| `official_model_id` | VARCHAR(128) NOT NULL | 第三方模型目录原始 ID，例如 `openai/gpt-5.4` |
| `request_name` | VARCHAR(128) NOT NULL | 实际请求模型名，例如 `gpt-5.4` |
| `api_type` | VARCHAR(32) NOT NULL DEFAULT `openai` | 接口类型，当前支持 `openai` / `anthropic` |
| `display_name` | VARCHAR(128) NOT NULL | 用户端展示名，例如 `GPT-5.4` |
| `is_hot` | TINYINT(1) NOT NULL DEFAULT 0 | 是否首页热门 |
| `sort_order` | INT NOT NULL DEFAULT 1000 | 后台和用户端排序 |
| `capability_score` | DECIMAL(10,4) NULL | 第三方能力评分 |
| `capability_source` | VARCHAR(64) NULL | 能力评分来源，例如 `OpenRouter` |
| `capability_updated_at` | DATETIME(3) NULL | 能力评分更新时间 |

索引补充：

1. `idx_models_provider_id (provider_id)`
2. `idx_models_api_type (api_type)`

字段使用规则：

1. 用户端展示必须使用 `display_name`。
2. 用户端自测和中转真实请求必须使用 `request_name`。
3. OpenRouter 抓取的原始 ID 必须保留在 `official_model_id`。
4. 中转报价抓取匹配模型时优先匹配 `request_name`，再匹配 `official_model_id`。
