# 后台模型删除与全量测试优化手册

## 本次修复范围

- 中转站编辑弹窗的模型报价列表支持多选批量操作。
- 模型报价支持批量启用、批量隐藏、批量删除。
- 编辑站点时模型报价不再依赖未注册的 Ant Design Form 字段，改为独立状态 `siteOffers`。
- 保存站点时以后端归档未触达报价，保证“删除即不可见”。
- 后台与公开查询默认排除已删除站点、已删除模型和 archived 报价。

## 关键问题

1. 编辑模型列表曾显示 0 条。
   - 原因：普通 Table 改造后，`offers` 不再是稳定注册的 Form 字段，`Form.useWatch("offers")` 和 `onFinish(values).offers` 会拿到空值。
   - 修复：模型列表统一读写 `siteOffers`，保存 payload 使用 `normalizeOffers(siteOffers, ...)`。

2. 删除模型保存后仍回显。
   - 原因：保存请求没有携带真实删除后的报价集合，后端无法判断哪些旧报价应归档。
   - 修复：后端 `UpdateAsync` 使用 `archiveMissing: true`，前端保存时传递当前完整可见报价集合。

3. 用户端 dev server 出现 `.next/server/chunks/903.js` runtime error。
   - 原因：Next dev 进程状态与 `.next` 构建产物不一致。
   - 处理：重启 public dev server 后公开页面恢复。

## 删除验收规则

- 页面点击删除后，当前列表必须立即消失。
- 保存并刷新后，列表不能再出现。
- 后台详情接口不能继续返回已删除报价。
- 用户端公开页面不能展示已删除报价。
- 逻辑删除允许使用 `archived`，但普通“全部”筛选不能包含 archived。

## 自动化测试建议

1. 使用临时站点和临时报价验证删除，不直接污染真实站点数据。
2. 执行路径：
   - 创建 3 条报价的临时站点。
   - UI 编辑站点，进入“编辑模型”。
   - 选择 2 条报价，执行批量隐藏并保存。
   - API 断言：2 hidden + 1 active。
   - 再次进入编辑，筛选隐藏模型，批量删除并保存。
   - API 断言：只剩 1 active。
   - 再次进入编辑，单条删除最后 1 条并保存。
   - API 断言：offers 为空。
   - 删除临时站点，断言列表不显示且详情接口返回 404。

3. 全量冒烟页面：
   - 后台：`/dashboard`、`/sites`、`/models`、`/model-providers`、`/offers`、`/tests`、`/risks`、`/jobs`、`/submissions`、`/articles`、`/settings`、`/sites/2`
   - 用户端：`/`、`/rankings`、`/models`、`/capabilities`、`/sites`、`/sites/xiangzai`、`/tests`、`/self-test`、`/articles`、`/submissions`

## 剩余优化项

- 前端 `typecheck` 当前被 Umi/Ant Design 依赖声明问题阻断，需要单独治理依赖版本或 tsconfig。
- 前端 `lint` 当前缺少可用 ESLint/Stylelint 配置，表现为 `import is reserved` 和 `global.less` 无配置。
- 用户端 `next build` 编译完成后进程退出码为 `3221225477`，需要单独排查 Windows/Next 构建收尾阶段崩溃。
- 后端存在 `System.Data.SqlClient 4.4.0` 中高危漏洞警告，应升级或替换依赖。
