# CheapAI 最小权限发布方案

## 目标

以后发布时不再把 root 密码交给 Codex。发布流程拆成两段：

1. 本地或 CI 构建镜像，产出 release tar、`manifest.json`、`SHA256SUMS`。
2. 服务器只执行固定的受限脚本：校验包、`docker load`、重建应用容器、reload proxy、健康检查。

## 推荐模式

### 模式 A：零服务器权限给 Codex

Codex 只负责本地验证和生成发布包，不连接服务器。

本地生成发布包：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\production\release\prepare-release.ps1
```

上传和执行由你自己完成：

```bash
scp -P 22 artifacts/release/<tag>/* root@<server>:/www/wwwroot/realllm.cn/releases/<tag>/
ssh -p 22 root@<server> 'bash /www/wwwroot/realllm.cn/deploy/production/release/apply-release.sh /www/wwwroot/realllm.cn/releases/<tag>'
```

优点：Codex 完全没有服务器凭据。缺点：你需要手动上传和执行。

### 模式 B：最小权限发布用户

由你在服务器上一次性安装受限发布用户。Codex 最多拿到 `cheapai-deploy` 用户的 SSH key，该用户只能写入 release 目录，并且只能免密 sudo 一个固定发布命令。

一次性安装：

```bash
bash /path/to/install-minimal-deployer.sh
```

安装后服务器约束：

- 发布用户：`cheapai-deploy`
- 可写目录：`/www/wwwroot/realllm.cn/releases`
- sudo 白名单：`/usr/local/sbin/cheapai-apply-release /www/wwwroot/realllm.cn/releases/*`
- 生产 `.env` 权限会设为 `0600 root:root`，发布用户不能读取。

发布命令：

```bash
scp -P 22 artifacts/release/<tag>/* cheapai-deploy@<server>:/www/wwwroot/realllm.cn/releases/<tag>/
ssh -p 22 cheapai-deploy@<server> 'sudo /usr/local/sbin/cheapai-apply-release /www/wwwroot/realllm.cn/releases/<tag>'
```

优点：可自动发布，但不再给 root。缺点：仍要保护 `cheapai-deploy` 的 SSH key。

## 发布脚本行为

`apply-release.sh` 会执行：

1. `sha256sum -c SHA256SUMS`
2. 给现有 `latest` 镜像打 `rollback-before-<tag>` 标签
3. `docker load -i *.tar`
4. `docker compose --env-file .env up -d --no-deps --force-recreate api jobs public-web admin-web`
5. `docker exec cheapai-proxy nginx -s reload`
6. 校验本机和公网入口：
   - `http://127.0.0.1:18080/api/health`
   - `http://127.0.0.1:13000/`
   - `http://127.0.0.1:18081/`
   - `https://www.realllm.cn/`
   - `https://www.realllm.cn/sites`
   - `https://www.realllm.cn/api/health`
   - `https://admin.realllm.cn/`

## 回滚

如果发布后异常，服务器上已有回滚标签：

```bash
docker tag realllmcn-api:rollback-before-<tag> realllmcn-api:latest
docker tag realllmcn-jobs:rollback-before-<tag> realllmcn-jobs:latest
docker tag realllmcn-public-web:rollback-before-<tag> realllmcn-public-web:latest
docker tag realllmcn-admin-web:rollback-before-<tag> realllmcn-admin-web:latest
cd /www/wwwroot/realllm.cn
docker compose --env-file .env up -d --no-deps --force-recreate api jobs public-web admin-web
docker exec cheapai-proxy nginx -s reload
```

## 安全边界

- 不把 root 密码交给 Codex。
- 不把 `.env`、数据库密码、JWT key、后台密码写入仓库、日志、文档或 release manifest。
- 不在小内存生产服务器上构建 Docker 镜像。
- 每次发布前必须先完成本地 P2 验收。
- 发布操作仍必须显式确认，因为它会影响线上容器。
