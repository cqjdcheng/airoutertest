# CheapAI 用户端现有功能文档

更新时间：2026-05-14

本文档只描述当前用户端已经落地的功能。用户端工程位于 `src/frontend/web-public`，技术栈为 Next.js，默认本地地址为 `http://127.0.0.1:3000`。

## 1. 用户端定位

用户端面向公开访客，不要求登录，核心目标是帮助用户比较 AI 中转站的价格、稳定性、风险和模型覆盖情况，并提供一次性自助测试能力。

当前用户端能力分为：

1. 首页总览与热门模型入口。
2. 模型目录。
3. 单模型排行。
4. 中转站目录。
5. 中转站详情。
6. 用户自助测试。
7. 测试记录浏览。
8. 模型能力榜。
9. 文章列表与详情。
10. 站点提交入口。

## 2. 全局交互与公共能力

### 2.1 站点品牌配置

用户端读取公开站点设置接口：

| 能力 | 说明 |
|---|---|
| 站点名称 | 来自 `site_settings.site_name` |
| 站点图标 | 来自 `site_settings.site_icon_url` |
| 页面布局 | 统一公共 Header、Footer、品牌 Provider |

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/site-settings` | 获取公开站点配置 |

### 2.2 数据请求约定

用户端 API 基础地址通过环境变量配置，页面优先使用服务端渲染读取公开接口。自助测试等交互表单使用客户端请求。

公开接口不要求登录，敏感信息仅在当前请求中使用，不写入数据库。

## 3. 首页

页面路径：`/`

代码入口：`src/frontend/web-public/app/page.tsx`

### 3.1 页面目标

首页用于快速给出平台当前状态和高频操作入口：

1. 平台统计概览。
2. 热门模型快捷自测。
3. 热门模型低价快照。
4. 稳定性快照。
5. 风险提示。
6. 数据口径说明。

### 3.2 热门模型逻辑

热门模型不再写死，来源于后台模型管理的 `is_hot` 和 `sort_order`：

1. 优先返回 `status = active` 且 `is_hot = true` 的模型。
2. 按 `sort_order` 升序展示。
3. 如果未设置热门模型，则回退展示启用模型中的前若干条。
4. 首页自测模块和快捷模型按钮共用这套热门模型数据。

热门模型字段：

| 字段 | 用途 |
|---|---|
| `modelSlug` | 用户端路由与模型标识 |
| `modelName` | 页面展示名 |
| `requestName` | 发起真实测试请求时使用的模型名 |
| `apiType` | 接口类型，当前支持 `openai` / `anthropic` |

### 3.3 首页测试模块

首页内嵌测试模块 `HomeTestWorkbench`：

1. 快捷模型读取热门模型。
2. 展示名称使用 `modelName`。
3. 请求模型名使用 `requestName`。
4. 用户手工输入模型时，以手工输入值优先。
5. API Key 只用于当前请求，不落库。

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/home/overview` | 首页统计、热门模型、价格卡片、稳定性卡片、风险提示 |
| GET | `/api/v1/public/self-tests/challenge` | 自助测试挑战题 |
| POST | `/api/v1/public/self-tests` | 提交一次自助测试 |

## 4. 模型目录

页面路径：`/models`

代码入口：`src/frontend/web-public/app/models/page.tsx`

### 4.1 页面展示

模型目录展示站内已收录模型，当前模型主数据主要来自 OpenRouter 抓取并可由后台手工维护。

列表字段包括：

| 字段 | 说明 |
|---|---|
| 模型名称 | 用户可读展示名，例如 `GPT-5.4` |
| 模型供应商 | 关联后台维护的模型提供商 |
| 模型请求名称 | 实际调用名，例如 `gpt-5.4` |
| 接口类型 | `openai` / `anthropic` |
| 官方输入价 | USD / 1M tokens |
| 官方输出价 | USD / 1M tokens |
| 当前最便宜站点 | 来自报价快照和排行快照 |
| 折算输入价 | 考虑充值倍率和赠送倍率后的输入价 |
| 折算输出价 | 考虑充值倍率和赠送倍率后的输出价 |
| 稳定性 | 来自模型排行快照 |
| 风险分 | 来自测试和风险聚合 |
| 中转覆盖数量 | 当前有报价的中转站数量 |

### 4.2 模型字段口径

模型展示名、请求名和第三方原始 ID 已拆分：

| 概念 | 示例 | 用途 |
|---|---|---|
| 模型名称 | `GPT-5.4` | 页面展示 |
| 模型请求名称 | `gpt-5.4` | 自助测试和中转真实请求 |
| 第三方原始 ID | `openai/gpt-5.4` | OpenRouter 等第三方目录标识 |

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/models` | 公开模型目录 |

## 5. 单模型排行

页面路径：`/rankings/[modelSlug]`

代码入口：`src/frontend/web-public/app/rankings/[modelSlug]/page.tsx`

### 5.1 页面目标

围绕单个模型展示中转站排行，帮助用户判断：

1. 哪个站点价格更低。
2. 哪个站点稳定性更高。
3. 哪个站点风险更低。
4. 当前排序和数据快照时间。

### 5.2 排行数据

排行数据来自 `model_ranking_snapshots`，当前支持按模型 slug 查询。

核心字段：

| 字段 | 说明 |
|---|---|
| `rankingType` | 排行类型，例如 `price` / `stability` / `value` |
| `window` | 统计窗口，例如 `7d` |
| `effectiveInputPriceUsd` | 折算输入价 |
| `effectiveOutputPriceUsd` | 折算输出价 |
| `availabilityScore` | 可用性 |
| `stabilityScore` | 稳定性 |
| `speedScore` | 速度 |
| `riskScore` | 风险分 |
| `finalScore` | 综合分 |

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/rankings/models/{modelSlug}` | 单模型排行 |
| GET | `/api/v1/public/rankings/cheapest` | 热门模型低价排行汇总 |

## 8. 用户自助测试

页面路径：`/self-test`

核心组件：`src/frontend/web-public/app/components/RelayTestPanel.tsx`

### 8.1 输入项

用户自助测试要求输入：

1. 中转站 API 地址。
2. API Key。
3. 模型名。
4. 是否流式请求。
5. 测试模式。
6. 挑战题答案。

### 8.2 安全口径

1. API Key 不落库。
2. 测试结果写入 `self_tests`。
3. 同步生成 `test_records` 统一记录。
4. 自测结果保留到 `expires_at`。
5. 自测记录属于用户主动发起，不直接进入公共排行。

### 8.3 输出结果

自测结果包括：

| 字段 | 说明 |
|---|---|
| `status` | 测试状态 |
| `firstTokenMs` | 首 token 延迟 |
| `fullResponseMs` | 完整响应耗时 |
| `riskScore` | 风险分 |
| `riskLevel` | 风险等级 |
| `matchScore` | 模型匹配度 |
| `tokensPerSecond` | 输出速度 |
| `checks` | 检测项明细 |

对应接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/self-tests/challenge` | 获取挑战题 |
| POST | `/api/v1/public/self-tests` | 创建自助测试 |
| GET | `/api/v1/public/self-tests/{id}` | 查询自助测试结果 |

## 13. 当前限制

1. 用户端当前不提供用户账号系统。
2. 自助测试 API Key 仅用于当前请求，不做长期可用性巡检凭据。
3. 公共排行依赖已有快照数据，快照缺失时展示空态或降级信息。
4. 直接访问后台 Umi 子路由 404 与用户端无关，用户端 Next.js 路由可直接访问。
